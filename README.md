# Brain Matcher 🧠 — 60FPS 3D Flip Edition

An interactive, high-performance 3D memory card matching game built with modern web technologies[span_0](start_span)[span_0](end_span). Features multiple gameplay modes, an adaptive AI opponent, profile customization, particle background animations, and custom sound effects[span_1](start_span)[span_1](end_span).

## 🚀 Key Features

* 🎮 **3 Distinct Game Modes**:
  * **1 Player Solo**: Campaign mode spanning 150 progressive levels[span_5](start_span)[span_5](end_span).
  * **VS Computer**: Play against a memory-based adaptive AI bot[span_6](start_span)[span_6](end_span).
  * **2 Player Local**: Pass-and-play local multiplayer across 50 hard levels[span_7](start_span)[span_7](end_span).
* 🎴 **60FPS 3D Card Mechanics**: Smooth hardware-accelerated 3D flip effects and fluid animations[span_8](start_span)[span_8](end_span).
* 🛍️ **Avatar Shop & In-Game Economy**: Collect coins by completing levels to unlock and equip custom player avatars[span_9](start_span)[span_9](end_span).
* 💡 **Power-Up System**: Use in-game coins for Hints, Card Peeks, Automatic Matches, and Time Freeze[span_10](start_span)[span_10](end_span).
* 🔊 **Synthesized Audio Engine**: Built-in sound effects using Web Audio API (no external sound files required)[span_11](start_span)[span_11](end_span).
* 🌌 **Dynamic Particle Background**: Animated interactive HTML5 canvas background system[span_12](start_span)[span_12](end_span).
* 💾 **Local Progress Saving**: Automatic saving for high scores, unlocked levels, stars, coins, and custom player names using `localStorage`[span_13](start_span)[span_13](end_span).

## 🎮 How to Play

1. Set up your player name(s) and select an avatar on the Profile page[span_14](start_span)[span_14](end_span).
2. Select your preferred game mode (1 Player, VS Computer, or 2 Player Local)[span_15](start_span)[span_15](end_span).
3. Choose an unlocked level from the Level Selector[span_16](start_span)[span_16](end_span).
4. Flip matching pairs of cards before time runs out to earn stars and coins[span_17](start_span)[span_17](end_span)!

### 💻 Keyboard Hotkeys
* `ESC`: Return to Level Selection screen[span_18](start_span)[span_18](end_span).
* `R`: Instantly retry current level[span_19](start_span)[span_19](end_span).
