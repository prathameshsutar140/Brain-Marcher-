Brain Matcher 🧠 — 60FPS 3D Flip Edition
​An interactive, high-performance 3D memory card matching game built with modern web technologies. Features multiple gameplay modes, an adaptive AI opponent, profile customization, particle background animations, and custom sound effects. 

​🛠️ Languages & Technologies Used

🌐 HTML5: Game structure, UI panels, canvas container, and semantic elements.  
🎨 CSS3: Hardware-accelerated 3D card flipping animations (preserve-3d), glassmorphism UI, keyframes, and custom responsive layouts.  
⚡ JavaScript (ES6): Core game state engine, Web Audio API sound synthesis, HTML5 Canvas particle rendering, and local storage data persistence.

🚀 Key Features


🎮 3 Distinct Game Modes:

1 Player Solo: Campaign mode spanning 150 progressive levels.  
VS Computer: Play against a memory-based adaptive AI bot.  
2 Player Local: Pass-and-play local multiplayer across 50 hard levels.  
🎴 60FPS 3D Card Mechanics: Smooth hardware-accelerated 3D flip effects and fluid animations.  
🛍️ Avatar Shop & In-Game Economy: Collect coins by completing levels to unlock and equip custom player avatars.  
💡 Power-Up System: Use in-game coins for Hints, Card Peeks, Automatic Matches, and Time Freeze.  
🔊 Synthesized Audio Engine: Built-in sound effects using Web Audio API (no external sound files required).  
🌌 Dynamic Particle Background: Animated interactive HTML5 canvas background system.  
💾 Local Progress Saving: Automatic saving for high scores, unlocked levels, stars, coins, and custom player names using localStorage.  

🎮 How to Play

Set up your player name(s) and select an avatar on the Profile page.  
Select your preferred game mode (1 Player, VS Computer, or 2 Player Local).  
Choose an unlocked level from the Level Selector.  
Flip matching pairs of cards before time runs out to earn stars and coins!  

💻 Keyboard Hotkeys

ESC: Return to Level Selection screen.  
R: Instantly retry current level. 

💻 Setup & Running Locally

Download or clone this repository.
Open 2players.html directly in any web browser.
